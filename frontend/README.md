# Frontend ConsultaEC (fase 1)

Para iniciar: `npm.cmd install` y después `npm.cmd run dev`.

La pantalla realiza **una sola llamada a la API propia** (`GET /api/v1/sistema/estado`). Vite redirige ese endpoint al orquestador local en el puerto 8080.

No se conecta directamente a los portales del SRI ni ANT. La aplicación completa y sus formularios se desarrollarán en las fases siguientes.
